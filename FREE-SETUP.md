# Бесплатная сборка и тестирование с Windows

Платная Apple Developer Program и аренда Mac не нужны для этого пути. Стандартная macOS-машина GitHub Actions выполняет сборку публичного репозитория, затем вы скачиваете IPA и подписываете его для своего iPhone через AltStore Classic.

Этот путь используется для сборки тестовых версий проекта. Статус каждой конкретной сборки смотрите в Actions; зелёный запуск означает, что тесты прошли и IPA был упакован на macOS-runner. При ошибке сохраните журнал запуска.

## 1. GitHub

1. Создайте бесплатный аккаунт на https://github.com или войдите в существующий. Платёжные данные для этого пути не добавляйте.
2. Создайте новый **Public** репозиторий, например `yandex-finance-ios-test`. Код станет общедоступным. В подготовленном архиве только код и искусственные тестовые данные, без банковских записей, паролей, сессий и сертификатов.
3. Распакуйте актуальный архив проекта. В репозиторий загрузите **содержимое** папки `YandexFinance-iOS`: `YandexFinance`, `YandexFinance.xcodeproj`, `Tests`, `scripts`, `.github`, документы и `.gitignore`. В корне репозитория должен лежать `YandexFinance.xcodeproj`, а не дополнительная внешняя папка.
4. Убедитесь, что файл `.github/workflows/build-ios.yml` появился именно по этому пути. Если веб-загрузка пропустила его, используйте Add file → Create new file, задайте этот путь и вставьте содержимое YAML из архива.
5. Откройте Actions → **Build iPhone IPA (free public runner)** → Run workflow. Запуск только ручной, без расписания. В Private-репозитории задача намеренно не запускается, чтобы не расходовать платные ресурсы.
6. Дождитесь зелёного результата. Внизу страницы запуска скачайте artifact `YandexFinance-unsigned-IPA` и извлеките `YandexFinance-unsigned.ipa`. Artifact хранится один день; если пропал, повторите ручную сборку.

Не загружайте папку старого Windows-прототипа: в ней могут находиться ваша база и профиль банка. Не создавайте GitHub secrets с Apple Account: для сборки без подписи Apple-авторизация не требуется.

## 2. Подписание и установка с Windows

Устанавливайте **AltStore Classic / AltServer Windows** с https://altstore.io, а не AltStore PAL. Актуальная инструкция проекта: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows . Требования к Apple-компонентам на Windows могут меняться: следуйте текущей инструкции AltStore.

1. Подключите iPhone к Windows-ПК и выполните установку AltStore по официальной инструкции. Подтвердите доверие компьютеру и включите Developer Mode на iPhone, если это требуется.
2. Учётные данные Apple вводите самостоятельно в локальном AltServer/AltStore. Наш GitHub workflow и приложение их не запрашивают.
3. Передайте собранный IPA на iPhone и установите через кнопку импорта собственного IPA в AltStore (My Apps).
4. После запуска приложения выполняйте проверку, указанную в README текущей версии. Для версии 25 сохранённую базу удалять не нужно: откройте вкладку «Финансы» и убедитесь, что операции текущего месяца попали в расчёт. Затем сверяйте итоги на одинаковом периоде с банком. Для этой проверки шестимесячную синхронизацию без отдельной необходимости не запускайте.

При бесплатной подписи срок действия приложения ограничен **7 днями**: до истечения обновляйте подпись средствами AltStore. Доступный способ обновления зависит от версии AltStore и настройки устройства. Установка/продление подписи — отдельная операция; чтение банка и просмотр сохранённых записей выполняются на iPhone.

Этот путь не даёт бессрочную установку без обслуживания. Совместимость AltStore с вашей версией iOS и вход банка внутри WKWebView ещё надо проверить. Если установка или авторизация не работает, перед оплатой чего-либо сначала разбираем конкретную ошибку.
