# Обновление 20: надёжность синхронизации

- Существующие записи и ключ хранилища сохраняются при установке поверх приложения.
- Автообновление учитывает перерыв с последней завершённой проверки и повторно проверяет минимум 7 дней. При отсутствии новой отметки проверки читает 183 дня.
- Кнопка «Продолжить загрузку истории» использует сохранённый месяц первичной загрузки. «Синхронизировать 6 месяцев» начинает её заново, не удаляя операции.
- Пропущенные карточки не позволяют объявить период полностью проверенным. Их количество видно в приложении.
- Быстрый пропуск знакомых операций отключён: статус и детали перечитываются.
- Сохранение промежуточного результата защищено номером прохода и последовательностью записей.
- Смешанный текст нескольких карточек отклоняется. Прогресс сохраняется при ошибке.

Проверять на iPhone: сохранность прежних записей, отмену и продолжение, повторный проход без дублей, изменение статуса ожидающей операции. Закрытое приложение не гарантирует фонового обновления. Локально выполняются синтетические JavaScript-тесты; сборка Swift и проверка устройства выполняются через GitHub Actions и iPhone.

В проекте текущий номер сборки — 20.


## Установка поверх версии 19

1. Распаковать архив. Заменить в репозитории папки YandexFinance, YandexFinance.xcodeproj, Tests и файл README.md.
2. Запустить существующую сборку в Actions. Дождаться успешного завершения тестов и сборки.
3. Скачать новый артефакт, распаковать IPA и подписать прежним Apple ID через AltServer.
4. Установить поверх Finance Test, не удаляя приложение. Проверить, что прежние операции остались.
5. Оставить приложение открытым для первой проверки. Повторить проверку после завершения: одинаковые операции не должны дублироваться. Если первичная загрузка остановилась, использовать «Продолжить загрузку истории».

## Известные ограничения

- Чтение зависит от разметки сайта банка; изменения сайта могут потребовать обновления парсера.
- Возобновление начинается с начала сохранённого месяца, а не точной строки. Лимит одного прохода — до 5000 карточек для длинного периода; очень большой месяц может потребовать доработки.
- Ошибки без доступного идентификатора сохраняются как незавершённые и требуют отдельной проверки. Они не скрываются под сообщением об успешном завершении.
- Перепроверка давних завершённых операций вне выбранного периода требует ручного запуска 6 месяцев. Автообновление расширяет период для незавершённых операций и зарегистрированных ошибок.
- Граница периода определяется по порядку истории банка. Полнота выгрузки всех банковских данных пока не подтверждена независимой сверкой.
