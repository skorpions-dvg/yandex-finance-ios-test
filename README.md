# Обновление 21: повторное чтение пропущенных операций

Текущий номер: текущий номер сборки — 21.

Во вкладке «Операции» появился раздел «Не удалось прочитать»: причина, месяц, идентификатор и доступное название/сумма из строки истории. Для новых ошибок сохраняется точная ссылка на карточку, для старых ошибок версии 20 — поиск по идентификатору в сохранённом месяце. Поиск старой ошибки может открывать другие карточки этого месяца, если ссылки отсутствуют в списке; они не добавляются и не изменяются этим поиском.

Нажмите «Перечитать эту операцию» либо «Найти и перечитать». При успешном чтении запись ошибки исчезает. Если ошибка повторяется, она остаётся в списке. Успех отдельной карточки не объявляет весь период проверенным.

Заменить папки YandexFinance, YandexFinance.xcodeproj, Tests и README.md. Собрать через существующий GitHub Actions и установить поверх Finance Test с прежним Apple ID, не удаляя приложение.

Все диагностические сведения остаются в зашифрованном хранилище приложения. В архиве только исходники и синтетические тесты. Банк может потребовать повторный вход. Фоновое обновление закрытого приложения не гарантируется. Проверка нескольких карточек пока сохраняется: её нельзя ослаблять без примера проблемной операции.
