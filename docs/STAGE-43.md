## 43.1 — фильтр отчётов (интерфейс)
Новый файл `YandexFinance/ReportFilterSheet.swift` и правки `ReportsView.swift`:
- `@State private var filter: ReportFilter = .none` в `ReportsView`; передать в `StructureContent`, `DynamicsContent`, `FlowContent` и дальше в `ReportSliceList.compute`; вызывать `ReportEngine.slices/bars/flow(…, filter: filter)`; добавить `filter.cacheKey` в ключи кеша этих вызовов.
- Кнопка «Фильтр» — в строке фильтров (`filters`) на вкладках «Структура», «Динамика», «Доходы и расходы» (не на «Остатках»), оформление как `pill`, значок `line.3.horizontal.decrease.circle`; при активном фильтре — подпись «Фильтр · N» (N = число исключённых групп и получателей) и акцентная заливка.
- Нажатие открывает sheet (`.presentationDetents([.medium, .large])`, фон `.appSurface()`):
  - сверху «Сбросить» (делает `.none`) и «Готово»;
  - секция «Категории»: все группы типа отчёта (для расходов — группы из `browser.history.expenseTaxonomy.groupNames`, для доходов — категории доходов из `ReportEngine.slices(…, mode: .income, filter: .none)` за выбранный период), у каждой переключатель (включена = не исключена); для «Расходов» группа «Переводы» тоже в списке;
  - секция «Получатели»: поле поиска и список до 50 крупнейших получателей выбранного периода (`ReportEngine.slices(…, grouping: .payees, filter: .none)`, сортировка как в движке), у каждого переключатель; ключ — `slice.id`.
  - при смене режима «Расходы/Доходы» исключённые группы другого режима из фильтра убирать.
- Пока фильтр активен, на «Структуре» и «Динамике»: строка «Все расходы/Все доходы» и центр кольца показывают сумму срезов (`total`), без строки «Возвраты» и без блока «Не входит в итог»; под кольцом маленькая подпись «Фильтр включён: …» не нужна — достаточно кнопки.
- «Остатки» фильтр не затрагивает.

## 43.2 — экран «Регулярные платежи» (интерфейс + чистые функции)
- Чистая логика без UI — новый файл `YandexFinance/RegularPayments.swift`: `periodTitle(intervalDays:) -> String` («Каждую неделю», «Раз в две недели», «Каждый месяц», «Раз в год», иначе «Раз в N дн.»), `nextDate(of pattern: FinancialEngine.RecurringPattern, now: Date, calendar: Calendar) -> Date` (от `lastDate` шагами периода — 30 это календарный месяц, 365 — год, 7/14 — дни — до первой даты не раньше сегодняшнего дня), `monthlyKopecks(of:)` (в пересчёте на месяц: 7 → ×30/7, 14 → ×30/14, 30 → 1, 365 → ÷12, округление до копеек). Только выдуманные названия (проверяет `privacy.test.js`).
