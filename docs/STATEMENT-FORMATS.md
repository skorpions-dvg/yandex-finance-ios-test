# Поддерживаемые PDF-выписки

Личные файлы не входят в репозиторий. Ниже описана только раскладка.

## Платёжный счёт

Заголовок банка и «Выписка по Договору за период с … по …». Таблица: «Описание операции», «Дата и время операции» (МСК), «Дата обработки» (МСК), «Карта», «Сумма в валюте операции», «Сумма в валюте Договора». Описание переносится на несколько строк, дата — `dd.MM.yyyy`, время — `в HH:mm`. Карта необязательная, `*NNNN`. Две суммы со знаком, десятичной запятой и символом ₽. В одном PDF могут последовательно находиться несколько выписок.

## Сейв

В преамбуле — «Договор банковского вклада до востребования для физических лиц», заголовок периода тот же. Таблица из трёх колонок: «Описание операции», «Дата операции» (МСК), «Сумма в валюте Договора». Времени и карточной колонки нет. Дата `dd.MM.yyyy`; сумма со знаком плюс или минус, пробелами между разрядами, десятичной запятой и ₽. Заголовок таблицы повторяется на каждой странице; входящий/исходящий остаток и номер страницы не являются операциями.

«Капитализация процентов», начисление/выплата процентов — проценты; «Перевод между счетами одного клиента», пополнение/вывод — собственное перемещение. Дата хранится как полдень по Москве с точностью до дня. Источник отмечен `statement-save:` и способом оплаты «Сейв (выписка)».

Оба источника импортируют архив раньше 01.10.2026; более новые строки остаются сканеру. Платёжная выписка должна покрывать архив до 30.09.2026, Сейву достаточно хотя бы одной архивной операции. Неизвестный формат и пустой архив отклоняются.

## Физические строки и повторный импорт

PDFKit: границы символов `characterBounds(at:)` группируются по вертикальному пересечению. Текст выделяется внутри полного прямоугольника символа на высоту физической строки: узкий прямоугольник может пропустить крайние буквы или пунктуацию, а глобальный порядок `page.string` не используется для таблицы. Многострочные заголовки определяют границы колонок; многострочное описание относится к своей строке с датой и суммой. `parseRows` принимает ячейки с координатами, `parsePages` остаётся для текстовых тестов и документов без геометрии.

Перед сохранением показаны числа замен, исправлений описания, перенесённых и неоднозначных индивидуальных категорий расходов/доходов. Перенос требует единственного свободного совпадения даты, суммы и способа оплаты; правила получателей не изменяются. Сохранение всей пачки выполняется один раз после подтверждения. Изменившаяся после просмотра история не перезаписывается — нужно повторить выбор PDF.

Обычные операции Сейва, которые не являются процентами или собственным пополнением/выводом, проходят прежний классификатор описаний. Источник Сейва полностью исключён из движений карточного остатка; его собственные переводы не дублируют движения платёжной выписки.
